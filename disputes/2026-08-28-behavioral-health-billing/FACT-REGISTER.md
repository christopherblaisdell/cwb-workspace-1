# Fact Register — Evidence Tiers

**Created 2026-09-05.** Companion to [AUDIT-2026-09-05.md](AUDIT-2026-09-05.md).

This file exists because of one recurring failure in the case folder: a fact reported by
someone else in one document became "confirmed" in the next, and by the third document it was
in a letter signed by the patient. Every material assertion in this case now has **exactly one
home and exactly one tier.**

**Before any assertion goes into any outbound document, look it up here and use the tier's
required wording.** If it is not in this register, it does not go in a letter.

---

## The tiers

| Tier | Meaning | How it may be written |
|---|---|---|
| **W** | **Witnessed.** Christopher personally saw, heard, or did this. | Flat declarative. *"I saw…" / "I heard…"* |
| **D** | **Documented.** An artifact exists, in hand, that establishes it. | Flat declarative, with the document cited. |
| **T** | **Told.** Someone else reported it. Hearsay, possibly double hearsay. | *"I was informed by \_\_\_ that…"* — **the attribution travels with the fact into every document, without exception.** |
| **I** | **Inferred.** A conclusion drawn from W, D, or T facts. | *"Based on \_\_\_, I believe…"* Never stated as observation. |
| **U** | **Unverified.** Asserted somewhere in the folder with no established basis. | 🚫 **Does not appear in outbound documents at all** until it moves tier. |
