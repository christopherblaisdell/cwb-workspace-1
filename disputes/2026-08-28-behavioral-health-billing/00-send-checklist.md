# Send Checklist

Run through this **every time** you send a letter in this case file. The goal is that
six months from now you can prove, with third-party evidence, exactly what you sent
and exactly when they received it.

## Before you send

- [ ] All `[BRACKETED]` placeholders replaced. Search the file for `[` to confirm.
- [ ] Your full legal name matches the name on the account and on the insurance card.
- [ ] Account number, MRN, and dates of service are correct and appear on page 1.
- [ ] Date on the letter matches the date you actually mail/fax it.
- [ ] Letter is signed. Print, sign in ink, scan. An unsigned records request can be
      rejected as invalid under HIPAA.
- [ ] Photo ID copy attached (required for most records releases). Redact nothing
      except, if you wish, the ID number's last digits — but expect pushback if you do.
- [ ] Made a PDF of the exact outgoing document and saved it to
      `evidence/YYYY-MM-DD-NN-letter-name-SENT.pdf`.

## Sending — do all of these on the same day

- [ ] **USPS Certified Mail, Return Receipt Requested** to the billing address.
      - Record the tracking number here and in the log.
      - Ask the clerk for **Certificate of Mailing (PS Form 3817)** as well.
- [ ] **USPS Certified Mail, Return Receipt Requested** to Medical Records / HIM
      (separate department, often a different address).
- [ ] **Fax** to billing fax number. Save the confirmation page as PDF.
- [ ] **Fax** to medical records fax number. Save the confirmation page as PDF.
- [ ] **Email** to every address you have: billing@, medicalrecords@, patient
      advocate, compliance/privacy officer, administrator/CEO. Request a read receipt.
- [ ] **Patient portal** secure message with the same text. Screenshot the sent
      confirmation with visible timestamp.
- [ ] Optional but strong: Certified Mail copy to the **registered agent** of the
      corporate entity (Secretary of State business search).

## After you send

- [ ] Add a row to [communication-log.md](communication-log.md) with date, method,
      recipient, tracking/confirmation number, and the deadline it triggers.
- [ ] Calendar the deadline (30 days for HIPAA records; whatever you stated in the
      letter for billing).
- [ ] When the green card / e-receipt arrives, scan it to
      `evidence/YYYY-MM-DD-NN-letter-name-DELIVERY-PROOF.pdf` and update the log with
      the actual delivery date and signer's name.

## Evidence file naming convention

```
evidence/2026-08-28-01-records-request-SENT.pdf
evidence/2026-08-28-01-records-request-FAX-CONFIRM-billing.pdf
evidence/2026-08-28-01-records-request-FAX-CONFIRM-him.pdf
evidence/2026-08-28-01-records-request-EMAIL-SENT.pdf
evidence/2026-08-28-01-records-request-PORTAL-SCREENSHOT.png
evidence/2026-09-02-01-records-request-DELIVERY-PROOF.pdf
```

## Things that will hurt your case — don't do them

- Don't dispute over the phone with no written follow-up.
- Don't make a partial payment "to be safe." In some states partial payment restarts
  the statute of limitations and can be argued as acknowledgment of the debt. If you
  want to pay something, do it only under a written agreement that preserves your
  dispute.
- Don't miss the insurer's appeal deadline (typically 180 days from the EOB date)
  while waiting on the facility. Run those tracks in parallel.
- Don't ignore a collections letter. You have a hard 30-day window to demand
  validation — see [07-collections-debt-validation.md](07-collections-debt-validation.md).
- Don't send originals of anything.
- Don't threaten anything you aren't willing to actually do. Every deadline you state,
  you must follow through on.
